# shearrss

Shear lightweight rss statistics from stdin samples.

**Site:** https://theworker02.github.io/shearrss/

## Install / run

```bash
git clone https://github.com/theworker02/shearrss.git
cd shearrss
node src/cli.js
node --test
```
